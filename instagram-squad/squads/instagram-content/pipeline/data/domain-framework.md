# Domain Framework — Squad "instagram-content"

Framework operacional que orienta todo o pipeline: da pesquisa de pauta à revisão final.

## 1. Um Tema, Múltiplos Ângulos

O squad nunca trabalha com múltiplos temas por rodada. Cada execução foca em UM tema (definido pelo usuário no Step 1) e gera MÚLTIPLOS ângulos editoriais sobre esse tema (gerados pela pesquisadora no Step 2, escolhidos pelo usuário no Step 3). Um ângulo é a lente emocional usada para contar aquele tema — nunca um assunto diferente.

Exemplo: tema "avaliação técnica de imóveis" pode gerar os ângulos "medo de perder o negócio por falta de avaliação", "prova social de um caso real", "mito de que avaliação é burocracia desnecessária" — todos sobre o MESMO tema, com emoções diferentes.

## 2. Um Ângulo, Três Formatos

Depois do ângulo escolhido, os três criadores (Feed, Reels, Stories) trabalham em paralelo, todos a partir do mesmo `selected-angle.md`. Isso garante consistência de mensagem entre os formatos, mesmo com tom e profundidade diferentes:

- **Feed:** aprofunda o argumento, constrói autoridade, é o formato "salvável".
- **Reels:** entrega o mesmo argumento de forma rápida e visual, para alcançar quem ainda não segue o perfil.
- **Stories:** trata o mesmo tema de forma íntima e conversacional, para quem já segue, com elemento interativo.

## 3. Checkpoints em Toda Decisão do Usuário

O pipeline nunca avança sozinho em decisões que pertencem ao usuário: foco da pesquisa (Step 1), ângulo (Step 3), aprovação do conteúdo antes de gerar visual (Step 7) e aprovação final antes de considerar o run concluído (Step 10). Isso segue o princípio "nunca colocar uma etapa de execução (visual/publicação) logo após uma etapa de criação sem checkpoint no meio".

## 4. Ciclo de Revisão com Limite

Se o Revisor rejeitar o conteúdo, o pipeline volta ao Step 4 (recriação completa dos três formatos, nunca ajustes pontuais isolados). Depois de 3 ciclos com os mesmos problemas recorrentes, o processo escala para decisão do usuário em vez de reprovar indefinidamente — evita loop infinito de revisão.

## 5. Regra de Negócio Inegociável

Nenhum conteúdo gerado por este squad pode prometer resultado de aprovação de crédito, taxa ou prazo de financiamento como garantia. O conteúdo educa sobre o PROCESSO (como funciona a avaliação, como funciona a liberação por etapa, o que um projeto bem feito evita de dor de cabeça), nunca sobre o RESULTADO de uma análise bancária, que não está sob controle da César Couto Arquitetura. Essa regra é um gatilho de rejeição automática no Revisor, independentemente da pontuação geral.
